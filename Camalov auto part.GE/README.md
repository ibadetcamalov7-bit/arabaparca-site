# TONY Auto Parts

ავტონაწილების მაღაზია — HTML, CSS, JavaScript და Node.js.

## გაშვება
1. დააყენე Node.js 18 ან უფრო ახალი ვერსია.
2. გახსენი პროექტის საქაღალდე VS Code-ში.
3. ტერმინალში გაუშვი `node server.js` (ან `npm start`). დამატებითი პაკეტები საჭირო არ არის.
4. ბრაუზერში გახსენი http://localhost:3000 . ტერმინალი დატოვე გაშვებული.
5. კოდის ცვლილების შემდეგ განაახლე გვერდი. სერვერის კოდის ცვლილებისას გადატვირთე სერვერი.

## ფაილები
- public/index.html — გვერდის სტრუქტურა.
- public/style.css — დიზაინი და მობილურ ეკრანზე ადაპტაცია.
- public/app.js — ძიება, ფილტრები, დალაგება, მართვის ფორმა და WhatsApp.
- server.js — HTTP სერვერი, მონაცემების შემოწმება და API.
- data/catalog.json — პროდუქტები და ტელეფონი. მონაცემები სერვერის გამორთვის შემდეგაც ინახება.

## გამოყენება
მართვის პანელში შეგიძლია პროდუქტის დამატება, რედაქტირება და წაშლა. ტელეფონი მიუთითე ქვეყნის კოდით, მაგალითად +995. WhatsApp-ის ღილაკი ამ ნომერს იყენებს. ფასები მოცემულია ლარში. პროდუქტები და ფასები სადემონსტრაციოა. რეალური სურათისთვის მიუთითე HTTPS ბმული.

## მუშაობის პრინციპი
ბრაუზერი მონაცემებს იღებს GET /api/catalog მოთხოვნით. JavaScript ქმნის პროდუქტის ბარათებს და ასრულებს ძიებასა და ფილტრაციას. მართვის ფორმა აგზავნის PUT /api/catalog მოთხოვნას. სერვერი ამოწმებს მონაცემებს და ინახავს JSON ფაილში. SQL ბაზა საჭირო არ არის.

## შეზღუდვები
პროექტი განკუთვნილია ლოკალური სასწავლო დემონსტრაციისთვის და მუშაობს მხოლოდ 127.0.0.1-ზე. ადმინისტრატორის ცალკე ავტორიზაცია და ონლაინ გადახდა არ არის დამატებული. საჯაროდ გამოქვეყნებამდე საჭიროა ავტორიზაცია, მონაცემთა ბაზა და წვდომის შესაბამისი უფლებები. ერთდროულად მრავალი მომხმარებლის მომსახურებისთვის JSON-ის ნაცვლად გამოიყენე მონაცემთა ბაზა.
